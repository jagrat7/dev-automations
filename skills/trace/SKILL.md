# Trace

Explain how the work produced the result and where it came from.

- Start with the result, then connect the important steps that led to it. Explain why those steps mattered.
- Show where the information came from and how it was used. Distinguish sources you read from files or external resources you changed.
- Link directly to the relevant files, pages, or changes beside the explanation they support. Use absolute local file links, with line numbers when useful, and exact web pages rather than site homepages. For deleted files, link to a recorded change when available.
- Explain what changed in each relevant place and why.
