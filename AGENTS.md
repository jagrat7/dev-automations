When asked to install skills globally use `npx skills add <source> --skill <name> --global --yes --agent <cached-agents>`. Read `lastSelectedAgents` from `$XDG_STATE_HOME/skills/.skill-lock.json` (or `~/.agents/.skill-lock.json` when unset); unattended agent detection otherwise overrides the cache. If the cached selection is missing or empty, use `claude-code devin`. Let the CLI create links.
